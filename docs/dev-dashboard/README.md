# 外道不覚悟｜開発管制室

## 起動
`index.html` をWindowsのChrome / Edgeで開くだけです。セットアップやサーバーは不要です。iPhoneのブラウザでも表示できます。ただしブラウザによってはローカルファイルの保存領域が利用できないため、その場合は信頼できるHTTPSサーバーで配信することを推奨します。

## 主な機能
- 総合ダッシュボード：設計状況、未決事項、次のPC作業、ロードマップ
- 音声会話の記録：会話要約→仕様・シナリオ・未決・タスクなどへ転記
- システム仕様／物語・キャラクター／未決・保留／実装タスク／検証結果
- 変更申請、変更禁止（保護）カードの編集確認、操作履歴
- 次のPC作業パック／次の音声会話プロンプトの生成・コピー
- JSONバックアップの書き出しと統合／置換読み込み、Markdown出力

## データの注意点
- 記録はブラウザの `localStorage` に保存されます。**複数端末で自動同期はしません。**
- JSONを定期的に書き出し、別端末では「データ・設定」から読み込んでください。
- 初期データは2026年11月8日までの会話内容に基づく**要約**です。元の全チャットJSONやコード実物の一括取り込み・照合はしていません。
- 実装済・テスト合格などの過去会話の報告を、独立した現物検証済みと混同しないため、再検証要や証拠欄に明示しています。
- 車の運転中はこのダッシュボードを操作せず、停車後に入力してください。

## 推奨ワークフロー
1. 通勤中にChatGPTとハンズフリー音声で論点を詰める。
2. 会話の終わりに「確定／暫定／未決と理由／変更対象／変更禁止／PC作業／検証」をまとめてもらう。
3. 停車後、サイトの「音声会話の記録」にコピペで登録する。
4. 仕様・人物・タスクの必要なカードへ転記する。
5. Windows PCで「次のPC作業・引継ぎ」から作業パックをコピーし、実装する。
6. 検証結果を別カードへ保存し、未決事項を次回の音声会話に戻す。

## 構成と拡張
初版は依存のない単独HTML/CSS/JavaScriptファイル。すでに存在するゲームのDIとは**独立した管理ツール**です。ゲームコードの移動／衝突／描画を改変しません。
将来的に以下の責務で分割するとTypeScript/Viteへ移しやすくなります。
- `domain/record.ts`: 状態定義、ID、変更禁止ルール、型
- `services/recordRepository.ts`: 保存・取込／取出（現在はlocalStorage）
- `services/handoffGenerator.ts`: 音声プロンプト・PC作業パック
- `ui/*`: ビュー／フォーム／イベント
- `adapters/*`: ブラウザ保存、必要になった場合だけFirestoreなど

クラウドを導入する場合は、**認証・アクセス制御・バックアップ・料金・個人や非公開シナリオの保護**を先に設計してください。Firebase/Google Cloudは初期版には含めていません。

## 制限
- ChatGPTやSitesから自動で会話を読み込む機能は未実装。
- Sitesへの公開・ホスティング・Firebase同期は未実装。
- 変更禁止の保護はUI上の誤操作防止であり、改ざん不能なアクセス制御ではありません。
