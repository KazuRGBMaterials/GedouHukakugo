# 戦闘VER4 — 2026-11-23
このディレクトリは戦闘VER4の独立した保存版です。起動: `/battle/ver4/`。
- 5×5～15×15の可変盤面、最大4対4、草原・廃墟の地形、AUTO/手動の個別切替。
- 通常攻撃・強打は上下左右＋斜めの周囲8マスが射程。
- ジャンプ斬りはジャンプ直後の連続技。マンハッタン距離1～4以内の相手を選び、敵の隣の空きマスへ着地する。威力・スタミナの値はVER3と同じ。
- 攻撃相手はキャラごとに自動で選び、敵が複数いる場合はタップで変更可能。
- ★の1枠前に対象が発光し、敵をタップすると予約済みの次の攻撃を変更できる。
- ジャンプ斬りでは緑の着地候補をタップして上書き可能。手動指定先が埋まった場合は追尾しない。
- 着地先に空きがないときや敵が射程外へ移動したときは空振りする可能性がある。
- 先行予約ボーナス（威力、スタミナ、連携補助）は未実装。
- VER3は `../ver3/` に保管。
