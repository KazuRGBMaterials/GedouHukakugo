# 外道不覚悟 FIELD EDITOR v0.1

2026-11-08 — GitHub Pagesの独立エディター

**エディターURL：** https://kazurgbmaterials.github.io/GedouHukakugo/editor/  
**ゲーム本編：** https://kazurgbmaterials.github.io/GedouHukakugo/ （FIELD v0.7.0、エディターとは独立）

## 開発方針

FIELD v0.6.2は操作性が良いと評価された基準版としてGitHubに別ブランチ保存済み。
このエディターは **docs/editor/** に閉じ込めて追加し、既存のゲーム本体のファイル・UI・ゲームロジックは変更しない。

最小限の機能を先に実用化し、今後段階的に拡張する。スキル・衝突・入力などのゲームコアには依存しない。純粋なデータ管理は `map-schema.js`、画面・操作は `editor.js`、見た目は `style.css` として分離。

## 操作方法

- **石壁（1）、樹木（2）、水辺（3）、宝箱（4）**：キャンバス上に配置。石壁・水辺はドラッグすると範囲指定。
- **選択（V）**：クリック／タッチで選択。ドラッグで移動、選択したオブジェクトの右下のハンドルで拡大縮小。
- **道（5）**：複数回クリックして折れ線の道を敷く。ダブルクリックか Enter で確定。選択後、右欄から道幅変更。
- **開始位置（6）**：クリックでMAGEの出現位置を変更。
- **削除（E）**：対象をクリックして削除。選択中のオブジェクトは Delete/Backspace でも削除。
- **画面移動（H）**：ドラッグで視点移動。マウスホイールかズームボタンで拡大縮小。
- **グリッド**：表示／吸着のオンオフ、16/32/64単位を選択可能。
- **右側のプロパティ**：オブジェクトのX/Y/幅/高さ・衝突判定、道幅、フィールド名・大きさ。
- **戻す／進む**：Ctrl+Z、Ctrl+Y（MacはCommand系も可）、最大70履歴。
- **JSON保存／読込**：端末ブラウザに自動保存。別の端末で再開するにはJSONファイルを書き出して読み込む。
- **試遊モード**：エディター内の単純な移動・衝突テスト。PCは矢印キーまたはWASD。スマホは画面に現れる十字パッド。
- **初期マップに戻す**：オリジナルの障害物11個と道に戻せる（確認ダイアログあり）。
- 追加のマップ例：`examples/original-map.json`。

## JSONフォーマット

```json
{
  "schema": "gedo-field-map",
  "version": 1,
  "name": "古き遺跡への道",
  "width": 1600,
  "height": 1000,
  "spawn": {"x": 160, "y": 520},
  "objects": [
    {"id":"wall-1","type":"wall","x":225,"y":140,"w":330,"h":34,"solid":true}
  ],
  "paths": [
    {"id":"road-1","width":76,"points":[{"x":95,"y":655},{"x":275,"y":620}]}
  ]
}
```

対象オブジェクト種：`wall`、`tree`、`water`、`chest`。座標はワールド単位、開始位置も同じ座標系。受け入れるデータは `map-schema.js` で検証し、未知のオブジェクトやフォーマット版は拒否する。

## 現時点の制約（重要）

1. **本編ゲームのマップはエディターの保存で自動変更しない。** ゲーム本体 v0.7.0 のマップ表示と衝突ロジックは従来どおり。エディターの「試遊」は独立した軽量テストで、戦闘・スキルは含まない。
2. 次の段階で、ゲームのComposition Rootに`IMapRepository`相当のデータ読み込みを注入し、描画・当たり判定にJSONの可変配置を反映する。現状の固定配列の先頭5=壁、次3=木、次1=池という描画・ジャンプ構造に直接JSONを流し込んではならない。**型情報ベースの描画・衝突実装**を独立アダプタとして追加すること。
3. 保存先はブラウザのlocalStorage。iPhone/Windows PC間の自動同期ではない。GitHub PagesやFirebaseに自動アップロードされない。
4. 既存ゲーム用の木や宝箱のアートを再利用するが、エディター上の見た目はゲーム本編と完全一致ではない。高精度WYSIWYGや複数レイヤー、NPC、イベント、タイルブラシ、Firebase共同編集は将来の拡張予定。
5. 地形を重ねて配置することはできる。開始位置が壁の中にある場合、エディター試遊では最も近い安全位置へ自動補正する。
6. 自動保存に失敗する環境ではJSONを書き出して退避。ブラウザのサイトデータを消すと端末内の下書きは消える。
