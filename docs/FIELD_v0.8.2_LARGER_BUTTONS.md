# FIELD v0.8.2 — 操作ボタンを一回り拡大

日時：2026-11-08（JST）

## 要望
「ボタンはもう少し大きくして」

直前のv0.8.1で移動・ジャンプ・スキルの3動作同時操作を追加したため、タッチ操作時の押しやすさを改善。

## 仕様
- XYABの丸ボタン直径：PC等の広い画面 **58 → 68px**、幅391–740px **52 → 62px**、幅390px以下 **46 → 56px**。
- 高さ600px以下の画面（横向きスマホを想定）：**44 → 55px**。
- L/Rのボタン高さ：広い画面 **31 → 40px**、幅391–740px **27 → 36px**、幅390px以下 **25 → 34px**、高さ600px以下 **24 → 32px**。
- ボタンの菱形配置は維持し、左右パネル幅と中央揃え位置を調整。
- 画面が低い場合はボタン上の余白を狭くし、パネル全体の高さの増加を抑える。
- 左スティックの位置・大きさは変更せず、XYABとのタッチ領域の分離を維持。

## 変更箇所
`docs/index.html` 内のCSS末尾に `FIELD v0.8.2` の上書きスタイルを追加。タイトルと画面バージョン表記をv0.8.2に更新。

**ゲームエンジンの31モジュールはすべて未変更。**
ボタンのID、pointerdown/touchstart、Bジャンプ、Yスキル、L/R選択、iPhoneの3本指操作、4スキルの性能、当たり判定、カメラ、Firebase、エディターは変更しない。

## 検証
- 31モジュールの構文確認、原文一致。
- CSSの構造チェック。
- デスクトップ、標準スマホ、狭いスマホ、320px幅の端末、横向きスマホ、低い画面でボタン同士と左スティックの幾何学的な重なりがないことを静的モデルで確認。
- 静的チェックは合計24項目合格。
- iPhone Safari / Windows実機でのタッチの押しやすさは未検証。

## ベースライン
操作性良好基準版：`baseline/field-v0.6.2-good-controls-20261108`。本改修では触れない。
