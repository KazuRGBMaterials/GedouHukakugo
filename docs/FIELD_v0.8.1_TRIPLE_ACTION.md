# システム001 — FIELD v0.8.1 三動作同時：移動＋ジャンプ＋スキル

保存日：2026-11-08（JST）  
前版：FIELD v0.8.0（コミット `8f807d5daa5af1a6a5127990a3249808daf847a9`）

## ユーザー要望

「ジャンプ移動しながらスキルも発動できるようにして。(3動作同時) 今は2つまでしかできないよう。」

目標：iPhoneの左仮想スティック（移動）＋右手のB（ジャンプ）＋Y（スキル）を互いに独立して操作。ジャンプ中も方向入力を保持し、発動中のキャラ本体モーションとVFXを表示する。PCの矢印移動＋Zジャンプ＋Aスキルも維持。

## 原因と修正

現行コードの `/src/actions/ActionButtons.ts` ではB/Yの `pointerdown` と `touchstart` はそれぞれ独立しており、第三指 `isPrimary=false` も受け取る。
`/src/skills/SkillMotionSystem.ts` の `cast()` にジャンプ禁止条件はない。

**実際の確認できた描画上の問題**は `/src/adapters/ArcaneSkinRenderer.ts` の `drawPlayer` が空中で `drawAirborne` のあと即 `return` すること。そのためスキルを発動しても空中ではMAGEのスキル用本体ポーズ（伸ばした腕・剣・合掌・左拳）が描画されず、「同時に使えない」と誤認しやすい状態だった。

v0.8.1では：
- 地上用に使っていたスキル本体ポーズを `drawActionPose(player,motion)` に抽出して共通化。
- 空中は従来の片足を上げた姿勢を描いた**直後に**、発動中スキルの本体ポーズを重ねて表示。
- スキル4はモーションの終了後も突撃中なら拳を前に出す構えを補間。
- ゲームXメニューに操作説明を追加。
- VFX、8方向MAGE画像、独立ボタン入力、各スキルの飛翔体・クールダウン・突撃方向補正を維持。

## 対象・保護

**既存の変更モジュールは一つだけ**：`/src/adapters/ArcaneSkinRenderer.ts`（`docs/index.html` 内の内蔵モジュール）。

変更禁止として維持：`ActionButtons`、`JoystickInput`、`KeyboardInput`、`ActionState`、`SkillSystem`、`SkillMotionSystem`、`SkillMotionMovementSystem`、`AbilityMovementSystem`、`PreviewAbilityMovementSystem`、`GameEngine`、`JumpRenderer`、`world.ts`、Firebase関連、旧v0.6.2ベースライン。

スキル2は短距離の踏み込み直後約0.14秒、スキル3は約0.24秒の硬直が従来どおり**残る**。同時入力で発動はできるが、移動速度が短時間止まるのは設計仕様。スキル1は移動硬直なし。スキル4は既存の空中突撃・方向修正を維持。

## 自動テスト結果

- 31内蔵モジュール構文テスト合格。
- 疑似DOMの三本指同時入力：スティック保持(pointerId=101)、Bでジャンプ(pointerId=102)、Yで炎弾(pointerId=103)。ジャンプ中の移動継続、B/Yがスティックをキャンセルしないこと、Safari `pointerdown`＋`touchstart`＋合成`click` の二重発動抑止を含む15項目が合格。
- `touchstart` のみが届く場合のB/Y独立入力でも発動を確認。
- 通常フィールド・エディタープレビューの両方で、**8方向 × 4スキル × 2レンダラー = 64パターン**の空中モーション／発動テストを実施。関連する全134項目が合格。
- ジャンプ描画では片足を上げる `drawAirborne` とスキル姿勢 `drawActionPose` が同フレームに実行されることを確認。

**未検証**：iPhone Safari実機の三本指同時タッチのイベント配送（OS独自の三本指ジェスチャーでキャンセルされる可能性）。疑似イベントを使用した自動テストであり、実機の保証ではない。

## 実機チェック

1. 左手親指でスティックを右に倒し続ける。
2. 右手の指でBをタップし、ジャンプ中にYを押す。Bを押しっぱなしにする必要はない（ジャンプは約0.55秒）。
3. Yで炎弾が空中から飛び、片足上げのMAGEに前へ突き出す腕が表示されるか。
4. Bを押したまま第三指でYを押した場合にも、Y発動が可能か。
5. スキル2/3/4でも空中の剣・合掌・前方左拳の動作を確認。2/3の短い移動硬直は従来のまま。
6. エディタープレビュー、PCの矢印＋Z＋A、ジャンプ中の壁抜け、スキル連射クールダウンに退行がないか。

実機でスキル自体が発動しない場合は、画面の「Y：○○ 発動」のトーストが出るかを確認し、入力イベント未配送とグラフィック不表示を切り分ける。
