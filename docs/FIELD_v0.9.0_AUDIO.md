# 外道不覚悟 — FIELD v0.9.0 オリジナルBGM・効果音導入

作成：2026-11-10（JST）

## 要望
「効果音と音楽をつけて」

既存FIELD v0.8.4をベースに、システム001に**オリジナルの探索BGMと、キャラクター行動に連動した効果音**を追加。

## 現状実装（音源と操作）
- ゲームの右上に `♫ 音をON / ♫ 音をOFF` ボタンを追加。音声は**初期状態OFF**で、ユーザーのボタン操作があって初めてWeb AudioのAudioContextを生成・再開する。Safari/iPhoneの自動再生ポリシーに配慮。
- Xメニューに「BGM」と「効果音」の独立音量スライダー（各0〜100）を追加。設定はブラウザの `localStorage` キー `gedo-field-audio-v1` へ保存。次回は音量だけ復元し、自動再生しない。
- BGM：オリジナル仮曲 **「Veiled Shrine／帳の魔導遺跡」**。Dマイナーを中心とした92BPM、64個の8分音符（8小節）からなるループ。旋律、低音、鐘風アルペジオ、持続音、低音パルス、軽い打楽器を、Web Audio APIの発振器・ノイズでリアルタイム合成。**既存商用曲や既存のゲーム音楽を複製していない。**
- 効果音：ジャンプ、着地（空中スキル2）、走行時の足音、ダッシュ開始、L/Rでのスキル切替、炎弾チャージ開始・長押し中の上昇する持続音・発射音（大きさで変化）・着弾、スキル2通常斬撃、スキル2空中突撃と地面への衝撃音、スキル3レーザー、スキル4突撃を実装。
- 炎弾のチャージ音は、既存 `ChargedFireSkillSystem` の `elapsed` に応じて周波数と音量が変化する。発射／キャンセル／音OFF／リセット時は止まる。
- 歩行音はゲーム内で実際に移動した座標距離に応じて鳴る。停止時・空中ジャンプ中は連打しない。
- 既存ゲーム本編と `?editorMap=1` のフィールドエディター試遊モードの両方に適用。
- 音声が未対応または音OFFでも、ゲーム操作や描画は従来どおり成立する。

## DIアーキテクチャ（変更を限定）

`docs/index.html` の内蔵モジュールは36→41個。**新規モジュール5個**：
1. `/src/audio/ArcaneAudioEngine.ts`: Web Audioコンテキスト、各音声バス、音量、オリジナルBGMの軽量先読みスケジューラー、合成効果音を管理。外部ファイル不要。
2. `/src/audio/SoundActionState.ts`: 従来ActionStateを継承し、ジャンプ・スキル切替・ダッシュ開始の成功時に音を呼ぶ。
3. `/src/audio/SoundSkillSystem.ts`: 従来ChargedFireSkillSystemを継承し、スキル発動やチャージ・着地・着弾イベント時に音を呼ぶ。
4. `/src/audio/AudioFrame.ts`: 既存BrowserFrameをラップし、描画更新後にBGMスケジューリングと移動時の足音を更新する。
5. `/src/audio/AudioControls.ts`: 音のON/OFF・BGM/効果音の独立音量のUIアダプタ。

変更した**既存ゲームモジュールは `/src/main.ts` のDI結線のみ**。本体エンジン、移動、当たり判定、UIのタッチ操作、3本指同時操作、ジャンプ、4スキル、スキル2の空中斬り込み、炎弾のチャージ／精密照準、Firebaseの各ソースは一切改変していない。

そのほか `docs/index.html` の画面側に音声ボタン・設定UI・CSS・バージョンを追加した。

## 検証済みと未検証

自動テスト済み：
- 41内蔵モジュールのJavaScript構文。
- AudioContextをボタン操作前に生成しないこと、ON/OFF切替、AudioContext再開、独立BGM/SFX音量設定、保存と読み戻し、OFF時の音源スケジュール停止。
- 合成音の接続先が正規のAudioNodeであること、発音時刻・停止時刻が有効であることを模擬Web Audioで確認。
- ジャンプ、スキル切替、通常斬撃、炎弾チャージ開始・発射・チャージ音停止、空中斬撃・着地衝撃。
- BGMの複数拍にわたるスケジューリング（音を再生するイベントの継続）、AudioFrameの既存ゲームループへの委譲。
- 操作パネルでのON/OFF・音量スライダー操作とクリーンアップ。

**重要：iPhone Safari、Windowsブラウザの実スピーカーでの音質・音量バランス・再生持続は未確認**。上記は模擬Web Audio APIでの構造・機能テストであり、実際の聴感での承認は別途必要。

## 次の改善・制作工房との将来的連携

ユーザーの設計方針「AIでドラフト制作 → 最後は自分で編集・採用」に従い、今回のBGM/SFXは**音響の仮実装・ドラフト**として扱う。現在のWeb Audio合成器を `IAudioPort` 相当の役割に置き、今後制作工房の「音楽」「エフェクト」エディターで作成・承認されたWAV/OGGなどをアセットとして登録して差し替えられるようにする。

ここでいう「音楽」は、今回追加した探索用のオリジナル曲であり、以前に検討していたレインのアップテンポ戦闘BGM・那由多のシーン曲などの**完成版を制作・組み込み済みという意味ではない**。将来シナリオイベントIDにBGMをひも付けて、探索・追跡・戦闘・イベント曲を場面で切り替えることを想定する。

## 実機確認の要点
1. ゲームを開き「♫ 音をON」を押す。BGMとUI効果音が聞こえるか。
2. 移動・ジャンプ・炎弾の短押し／長押し→発射・スキル2/3/4を操作して効果音を確認。
3. Xメニュー内のBGMと効果音スライダーで別々に音量を0へ下げ、戻す。
4. 「♫ 音をOFF」で両方無音になることを確認。再度ONでBGMが再開することを確認。
5. iPhoneのサイレント設定、Bluetooth/イヤホン、画面のロック・復帰がある場合の動作は端末により異なるため実機で検証。
6. エディターから「本編で試す」でも同じ音声UIが使えるか。
