フィールド操作テスト v0.9.0

A: 決定 / B: ジャンプ
Y: スキル / X: メニュー
L・R: スキル切替

スキル1：炎弾 / 2：斬撃 / 3：レーザー / 4：超高速突撃（方向操作で曲がる）

炎弾：Yを押している間はチャージ・上下ドラッグで射出角度を微調整。離すと発射。 0.2秒以上の長押しで足を止め、約0.4秒で従来サイズ、約1.4秒で巨大弾になります。

ジャンプ中は石壁を通過できます（木・水辺・木箱は通過不可）。

3動作：スティック移動中にBでジャンプ、空中でYを押すとスキル発動（Bは押しっぱなし不要）。

スキル2は空中発動時のみ、向いている方向へ斜め下に突撃し、地面へ着地斬撃。地上では従来どおり。

音楽・効果音は画面右上の「♫ 音をON」で開始。Xメニューで音量を別々に調整できます。
